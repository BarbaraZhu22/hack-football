## 环境坑（务必记住）

- **不要运行 `npx next build`**：它会清空 `.next`，触发 WorkBuddy 的 safe-delete
  批量删除保护（阈值 50 次/轮），导致正在运行的 dev server 全线 500。
- 同类问题：`next dev` 启动时会清理 `.next/static/webpack/*.hot-update.json`，
  累积过多也会触发该保护并让 dev server 崩溃。解法是**重命名** `.next`
  （`mv .next .next.bak-HHMMSS`）而不是删除，让 Next 重新生成。
- 当前 `apps/web/.next.bak-141251`（约 342MB）是我留下的备份，可手动删除。
- dev server 必须用 Bash 工具的 `run_in_background` 启动；用 `(cmd &)` 脱离会在
  工具调用结束时被杀掉。
