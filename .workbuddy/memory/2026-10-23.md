## 3D implementation audit (insight request)

- Only two external models are actually used: `Superhero_Male_FullBody.gltf` (Quaternius Universal Base Characters [Standard], CC0 1.0, quaternius.com / itch.io, downloaded 2026-09-09, SHA-256 recorded in README) and `Standard_Run.glb` (Mixamo Standard Run clip, 53 channels, FBX2glTF v0.9.7 export, animation name mixamo.com)
- Note: `models/quaternius/README.md` mentions an AnimationLibrary.glb (46 animations) and two FullBody characters that are NOT shipped and NOT referenced in code. The only animation in use is Mixamo Standard_Run
- Models are stored twice: `components/three/models/` (served via `/api/models/[...assetPath]`) and `public/models/` (the actual useLoader path `/models/...`)
- Motion stack, three layers: (1) Mixamo clip retargeting (mixamo.js, 25-bone map, 0.18 s fade before contact blended with IK) (2) analytic IK poses (pose.js: poseTackler phases sprint/commit/slide/rise/stand, poseCarrier phases carry/fall/ground, solveLimb two-bone IK) (3) simulation driver (lib/incident-simulation.js: 3.3 s / 120 Hz / 397 frames of procedural physics, bezier tracks, phase state machine, fall angular-momentum integration, ball drag + Magnus)
- Ball (Ball.js) and pitch environment (Pitch.js: 68x105 m markings, 7.32x2.44 goals, crowd, ad boards) are fully procedural canvas textures plus parametric geometry. Zero external textures
- Render stack: three.js + @react-three/fiber + drei, 4 fixed camera presets + free orbit + reverse-angle PIP dual view
